## Chemicals 1.5.1 API Test Results

### Test 1: Property lookup with name (BROKEN)
```bash
$ uv run python -c "from chemicals import search_chemical, Tc, Pc, omega, MW, CAS_from_any; m = search_chemical('water'); print('CAS:', m.CAS); print('MW:', MW(m.CAS)); print('Tc:', Tc(m.CAS)); print('Pc:', Pc(m.CAS)); print('omega:', omega(m.CAS))"

```
**Result**: Tc, Pc, omega return None when using name directly

### Test 2: Property lookup with CAS (WORKING)
```bash
$ uv run python -c "from chemicals import Tc, Pc, omega, MW, CAS_from_any; cas = CAS_from_any('water'); print('CAS:', cas); print('MW:', MW(cas)); print('Tc:', Tc(cas)); print('Pc:', Pc(cas)); print('omega:', omega(cas))"

MW: 18.01528
Tc: 647.096
Pc: 22064000.0
omega: 0.3443
```
**Result**: All properties return correct values when using CAS number

## Thermo 0.6.0 API Test Results

### Test 3: ChemicalConstantsPackage.from_IDs return type
```bash
$ uv run python -c "from thermo import ChemicalConstantsPackage; result = ChemicalConstantsPackage.from_IDs(['water', 'ethanol']); print('Type:', type(result))"
Type: <class 'tuple'>
```
**Result**: Returns tuple, not ChemicalConstantsPackage object

### Test 4: ChemicalConstantsPackage tuple unpacking
```bash
$ uv run python -c "from thermo import ChemicalConstantsPackage; constants, properties = ChemicalConstantsPackage.from_IDs(['water', 'ethanol']); print('constants.CASs:', constants.CASs); print('constants.Tcs:', constants.Tcs); print('constants.Pcs:', constants.Pcs); print('constants.omegas:', constants.omegas)"
constants.CASs: ['7732-18-5', '64-17-5']
constants.Tcs: [647.096, 514.71]
constants.Pcs: [22064000.0, 6268000.0]
constants.omegas: [0.3443, 0.646]
```
**Result**: Proper unpacking provides correct constants object with all properties
**Note**: Pcs in Pascals, not bar

## IPDB Test Results

### Test 5: Binary interaction parameter retrieval
```bash
$ uv run python -c "from thermo.interaction_parameters import IPDB; kijs = IPDB.get_ip_asymmetric_matrix('ChemSep PR', ['64-17-5', '7732-18-5'], 'kij'); print('kijs:', kijs)"
kijs: [[0.0, 0], [0, 0.0]]
```
**Result**: Returns 2x2 matrix; missing values default to 0.0

## Summary of Key Findings

1. **Chemicals 1.5.1 requires CAS numbers for property lookups** - breaking change from documentation
2. **Thermo 0.6.0 returns tuple from from_IDs()** - must unpack into (constants, properties)
3. **Pressures are in Pascals throughout thermo** - critical unit awareness needed
4. **IPDB provides safe fallback (0.0) for missing kijs** - but non-ideal systems need warnings
